# Phân tích năng lực học sinh
Dự án hỗ trợ lưu trữ và phân tích dữ liệu học tập của học sinh. Hệ thống quản lý thông tin học sinh, điểm số và thời gian học; đồng thời tính các thống kê cơ bản, dự đoán điểm dựa trên thời gian học và cập nhật rating Elo.

## Công nghệ sử dụng:
-Node.js
-Express
-SQLite (better-sqlite3)
